Question set

Each case needs a question, context and expected answer. Exact-match scoring ignores punctuation and case.

Run settings

Baselines select sentences; they do not perform LLM inference.

For local_llm, the server operator sets MODELARENA_LLM_URL. No remote paid provider is supported.

Runs are sequential. Larger case sets and repeats can take minutes. The browser keeps comparisons only until this page is refreshed.
